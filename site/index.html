Description

A local-first client for YouTube Music. It searches anonymously, plays through mpv, and downloads with yt-dlp.

ytmusic-tui is a terminal client for YouTube Music. It searches through ytmusicapi in anonymous mode, plays through mpv, downloads through yt-dlp and ffmpeg, and keeps the library and playlists in a local SQLite database.

There is no account layer, no browser runtime, and no cloud sync. The interface is keyboard-first, with mouse support for tabs, lists and buttons. It runs in a terminal with 256 or true colour and Unicode, at 80×24 minimum; 100×30 is recommended.

The project is pre-1.0, used daily on a real music library, and candid about what it does not do. The code, documentation and site are in English. The application interface and messages are in Brazilian Portuguese.

Keyboard first

Every action has a key. The mouse works too.

Local by design

Library, likes and playlists live in a SQLite file on your machine. Nothing syncs to a cloud.

Downloads that tell the truth

yt-dlp and ffmpeg fetch the best stream and tag it. The interface shows what is actually on disk, including what is not.

Small on purpose

No Electron, no bundled browser. Just Python, SQLite, mpv and standard media tools.

Features

Six pieces, wired directly to each other. The terminal is the interface, not a compromise.

Parallel search
Songs, videos and albums in one query: up to 25 + 20 + 15 results, grouped by type, usually in about two seconds. No advanced filters.
Instant playback
mpv streams the selected audio quality. Space pauses, the arrow keys move through the queue, and a continuous queue keeps playing.
Whole-album downloads
Press A on an album to queue every track, skipping the ones already downloaded. MP3 320 kbps is the default; opus, m4a and flac are available.
A library on disk
Downloaded tracks are organised by album, plus standalone tracks. Playback reads the local file, not the network.
Real local playlists
Create, rename, reorder and play in order. Stored in SQLite, not on someone else's server.
Themes and diagnostics
Ctrl+T opens the 🎨 Temas tab with 27 themes (Catppuccin, Nord, Monokai, Solarized, GitHub, Kanagawa, Everforest and more). Arrow keys preview live; Enter saves the choice to config.toml. Run ytmusic-tui doctor for a masked, paste-ready environment report.

Video results play and download as audio; there is no video image. Adding a track to a playlist from search requires that track to be downloaded first.

Installation

Three steps. Linux is the validated platform; the app installs from GitHub, not PyPI.

Before you begin

Python
3.11–3.13 supported. 3.14 is not validated.
mpv
With libmpv. Mandatory; the app will not start without it.
ffmpeg
Required for downloads. Search and playback work without it.
Terminal
256/true colour and Unicode. 80×24 minimum; 100×30 recommended.
  1. 1

    System dependencies

    Install mpv with libmpv and ffmpeg. On Ubuntu, Debian, Linux Mint and LMDE:

    shell
    sudo apt install mpv ffmpeg python3-venv

    On Ubuntu and Debian you may also need libmpv-dev so Python can find libmpv.

    Other distributions
    Arch / Manjaro / EndeavourOS 
    sudo pacman -S mpv ffmpeg python
    Fedora 
    sudo dnf install mpv ffmpeg python3
    openSUSE 
    sudo zypper install mpv ffmpeg python3

    macOS is a community path, not officially supported. It may work with brew install mpv ffmpeg python; nothing is promised. Windows native is not supported; WSL2 is untested.

  2. 2

    Install the app

    Use pipx for an isolated environment and a launcher on your PATH.

    shell
    pipx install git+https://github.com/pr0sthetics/ytmusic-tui

    The app is not on PyPI yet; this installs straight from GitHub.

    Other installation methods
    pip, where --user installs are allowed 
    pip install --user git+https://github.com/pr0sthetics/ytmusic-tui
    From source 
    git clone https://github.com/pr0sthetics/ytmusic-tui
cd ytmusic-tui
python3 -m venv .venv
.venv/bin/pip install -e .
.venv/bin/ytmusic-tui

    On externally managed Python installs (Debian 12+, Ubuntu 23.04+, Mint, LMDE), pip refuses --user. Use pipx or a venv.

  3. 3

    Run it

    Start the interface, or check the environment first.

    shell
    ytmusic-tui
ytmusic-tui doctor

    --version prints the installed version; doctor checks the environment without opening the interface.

    Updating later: pipx upgrade ytmusic-tui

Files

Everything the app writes, and where it lives. Nothing here leaves the machine.

~/.config/ytmusic-tui/config.toml
Configuration. Every key is optional; the defaults are enough to start.
~/.local/share/ytmusic-tui/library.db
Local library and playlists, stored as SQLite. Likes are local and apply to downloaded tracks.
~/Music/YouTube Music/
Downloads by default: tagged files with embedded cover art, organised by album plus standalone tracks.
~/.local/state/ytmusic-tui/log/ytmusic-tui.log
JSON Lines log for diagnosis. Home paths become ~, URLs lose query strings and tokens, and credential headers are redacted before writing.
~/.cache/ytmusic-tui/
Cache. Safe to remove when the app is closed.

The app writes no cookies, no telemetry and no account state. Copy a log line into an issue only after checking the redaction.

Doctor

ytmusic-tui doctor checks versions, libmpv, mpv, ffmpeg, directories and the library database read-only. Its output is masked so it can be pasted into an issue.

shell
ytmusic-tui doctor

Caveats

What it does not do, before you install. The full list and roadmap are in the repository.

Known limitations

Pre-1.0
  • No account, no sync.

    Likes and playlists are local; account playlists, recommendations and cloud likes do not show up.

  • Search has limits.

    Up to 25 songs + 20 videos + 15 albums per query, with no advanced filters.

  • 320 kbps is a conversion.

    YouTube typically serves ~128–256 kbps; MP3 320 standardises the files, it does not add quality.

  • The interface is in Portuguese.

    The code and documentation are in English; the app's messages are in Brazilian Portuguese.

  • Still on the roadmap.

    MPRIS, synced lyrics, equalizer, custom theme files and Last.fm/ListenBrainz are not here yet.

Also worth knowing: video results play as audio, and adding a track to a playlist from search requires it to be downloaded first.

FAQ

Short answers, no asterisks. If something is missing, the issue tracker is open.

Does it need a YouTube account?

No. Search, playback and downloads run anonymously. The app keeps a local library instead of syncing an account.

Where does my data live?

Everything stays on your machine: config in ~/.config/ytmusic-tui/, library in ~/.local/share/ytmusic-tui/library.db, downloads in ~/Music/YouTube Music/ by default, logs in ~/.local/state/ytmusic-tui/.

Does it work on macOS or Windows?

Linux is the validated platform. macOS is a community path (brew install mpv ffmpeg python) with nothing promised. Windows is not officially supported; WSL2 is untested.

How do I update?

pipx upgrade ytmusic-tui. If the version does not move (installs follow the default branch), force a fresh install: pipx install --force git+https://github.com/pr0sthetics/ytmusic-tui. Pin a tag to downgrade.

Can I change the theme?

Yes. Ctrl+T opens the 🎨 Temas tab. Use Up/Down for a live preview and Enter to apply and save. The 27 themes include Catppuccin, Nord, Monokai, Solarized, GitHub, Kanagawa and Everforest. Custom theme files are on the roadmap.

What if downloads break?

Downloads depend on yt-dlp, which tracks YouTube changes. Update the app and yt-dlp in the same environment.

Is this an official YouTube or Google app?

No. It is an unofficial open-source client, not affiliated with or endorsed by YouTube or Google. YouTube Music is a trademark of Google LLC.
